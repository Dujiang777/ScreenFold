# 屏风 · ScreenFold

**简体中文** · [English](README.en.md)

> 一块看起来不像视频的屏幕。

一个常驻桌面的小面板。标题栏是 `feed.aggregator.ts`，状态栏写着 `main · M 2 · Ln 42, Col 8`，
左边一排行号 —— 从任何角度扫过去，这就是一个打开的代码文件。

只有你主动要的时候，它才变成抖音 / B站 / 虎牙 / 快手。

---

## 快速开始

**双击 `start.cmd` 就行。** 不用开终端，不用敲路径，不需要 npm。

它自己会 `cd` 到所在目录、清掉 `ELECTRON_RUN_AS_NODE`、直接拉起 Electron，
所以放哪儿、从哪儿双击都不会出错。

要在终端里跑也可以，**注意路径**（`screenfold` 不在用户主目录下）：

```bash
cd /d "C:\Users\AMBITIOUS_YUAN\WorkBuddy\2026-09-17-15-42-00\screenfold"
npm start
```

> 环境里如果设了 `ELECTRON_RUN_AS_NODE`，Electron 会降级成纯 Node 并报
> `Cannot read properties of undefined (reading 'commandLine')`。
> `start.cmd` 已经帮你清了；手敲命令的话：`unset ELECTRON_RUN_AS_NODE`
> （Windows: `set ELECTRON_RUN_AS_NODE=`）

带参数运行时走前台模式，方便看输出（比如自检）：

```bash
start.cmd --shot=shots      # 自动出 12 张截图，跑完自己退出
```

## 怎么用（不用记任何键）

**日常就一件事：把鼠标移到窗口上。**

```
鼠标移进去  →  画面出现
鼠标移开    →  自动收回，变回假代码
```

就这样。没有任何按键需要记。

其余操作全部是「看得见 → 点一下」：

| 你想干什么 | 怎么点 |
|---|---|
| **换来源** | 鼠标移进窗口 → 底部浮出操作条 → 点 **来源**（也可以直接**滚轮**滚标签） |
| **换个伪装** | 操作条 → 点 **面具**（或点状态栏右下角的 `TypeScript`） |
| **改窗口大小** | 直接拖窗口的**四条边 / 四个角**（右下角有斜纹把手）；或操作条 → **尺寸** |
| **看快一点** | 操作条 → 点 **倍速**（1× / 1.25× / 1.5× / 2×，每个来源各记各的） |
| **页面上全是浮层** | 操作条 → 点 **净化**（盖掉登录引导、下载 App 横幅、开屏广告） |
| **钉住画面** | **双击画面** 就是钉住 / 松开；或操作条 → **钉住** |
| **静音 / 刷新 / 设置** | 操作条右侧三个图标 |
| **全都找不到？** | **在窗口里点右键**，所有东西都在那个菜单里 |
| **立刻收回** | 鼠标移开就行；实在急就点右键菜单里的「立刻收回」 |

操作条长这样（鼠标一进窗口就浮出来，不动鼠标 2.4 秒后自己让开）：

```
   ⌷ 来源   ▣ 面具   ⤢ 尺寸   ⏩ 倍速   ⚡ 净化   │   📌 钉住   🔊   ↻   ⚙
```

状态栏本身也是操作区，鼠标划过去会亮：

```
main ▾     M 2  ✓ 0  ⚠ 0                   296×578    TypeScript ▾      👁 钉住
└─ 点：换来源                                    └─ 点：尺寸  └─ 点：换面具     └─ 点：钉住
```

### 三个可选快捷键

**不用记，所有事鼠标都能干完。** 只有这几个万一顺手时用：

| 按键 | 作用 |
|---|---|
| `Alt` + `` ` `` | 钉住 / 松开画面 |
| `Alt` + `V` | 闪现画面几秒，到点自动收回 |
| `Alt` + `X` | 紧急收回（有人走过来） |

窗口里还有 `Ctrl+P` 搜来源、`Ctrl+,` 设置、`Ctrl+D` 钉住、`Esc` 收回、`1`~`5` 换面具
—— 都是可选的。因为这些键只在窗口聚焦时生效，不会漏给别的程序，也不抢任何 IDE 快捷键。

> 占用冲突了不影响使用，鼠标一样能操作。

## 为什么不容易被发现

四层，从外到内：

### 1. 「自洽」是最重要的一层（v3 重点）

一个伪装界面最容易穿帮的地方，不是像素不够多，而是**前后对不上**：

> 标签上写着 `media.player.tsx`，点开一看是 `route.ts` 的源码。

上一版就是这样 —— 三套面具的内容都是硬编码的同一份 Next.js 路由。切到别的来源，
文件名换了、内容没换。从背后扫一眼就够了。

现在改成**内容库**：每个来源绑定一份专属源码，**标签栏的文件名 / 面具里的代码 /
窗口标题** 三者永远是同一个文件。

| 地址栏显示 | 面具里实际是 |
|---|---|
| `feed.aggregator.ts` | Next.js 信息流路由：鉴权、限流、游标分页、排序 |
| `media.player.tsx` | React 播放器组件：播放状态、进度、倍速 |
| `live.room.ts` | 直播间：心跳、弹幕缓冲、礼物合并 |
| `stream.pipeline.ts` | 流式管道：背压、分帧、zstd 解压 |
| `realtime.socket.ts` | 实时通道：带抖动的指数退避重连 |
| `notes.index.tsx` | 笔记列表：无限滚动、防抖搜索 |
| `timeline.cache.ts` | 时间线缓存：内存 LRU + 落盘 KV、幂等合并 |
| `cdn.proxy.ts` | 媒体回源代理：Range 透传、白名单 |
| `qa.thread.tsx` | 问答线程：折叠、排序、投票 |

**代码评审**（diff）面具也不是写死的 —— 它按当前文件**现场生成** unified diff：
hunk 头 `@@ -14,9 +14,12 @@` 的行号和上下文行都取自真实源码，路径也跟着文件名走。
**构建日志**里的编译行也会提到当前这个文件。

设置里有一项 **「源码跟着标签走」**（默认开）。关掉之后就退回旧行为：面具内容固定不变。
不建议关，除非你就是要一个不变的东西。

### 2. 窗口层

- **不进任务栏**，也尽量不进 Alt-Tab
- 窗口标题跟着当前文件走：`media.player.tsx — inkstack — Visual Studio Code`
- **录屏保护**：开启后，会议共享屏幕、录屏、截图里这个窗口都不会出现
  （Windows 上走 `SetWindowDisplayAffinity`，共享时对方看到的是一块空白）

### 3. 外壳层（永远在场）

标签栏 + 行号槽 + 状态栏。这三样不管你在看什么都不会消失。
所以哪怕你完全没来得及做任何操作，远看也只是个编辑器面板。

内容区在「假代码」和「真画面」之间瞬时切换，没有淡入淡出 —— 不留中间帧。

**五套面具都是会动的**（静止的假界面反而可疑）：

| 面具 | 长什么样 |
|---|---|
| 源码 | 语法高亮的 TypeScript / TSX，光标闪烁、缓慢滚动、偶尔敲两个字再删掉 |
| 代码评审 | 由当前文件现场生成的 git diff，绿红行 + 真实 hunk 头 |
| 构建日志 | `next dev` 构建日志，每 1~2 秒追加一行，带 ✓/○/▲ 着色 |
| 跑单测 | `vitest run` 输出，用例一条条跑出来，状态栏的构建点会跟着呼吸 |
| 提交历史 | `git log --graph`，分支交错、哈希上色、commit message 分类高亮 |

状态栏的 `Ln 42, Col 8` 会跟着滚动位置真实变化，左下的 `M 2` 也跟着当前面具变。

### 4. 兜底层（这才是关键）

「没来得及隐藏」这件事本身被消解掉了，因为你**不需要主动隐藏**：

| 机制 | 说明 | 默认 |
|---|---|---|
| 鼠标移进即显示 | 这就是主路径，不用按键 | 开 |
| 移开即收回 | 鼠标离开窗口 **0.4 秒**后自动回面具 | 开 |
| 失焦即收回 | 点到别的窗口立刻回面具 | 开 |
| 收起即静音 | 画面收回的同时静音，不留声音破绽 | 开 |
| 画面露出时隐藏指针 | 鼠标不动 2 秒，连指针一起消失 | 开 |
| **锁死面具** | 开了之后怎么移都不露画面，旁边有人时用 | 关 |

也就是说：**日常状态是面具，你只是把鼠标搭上去看一眼。** 手一挪，它自己就收回去了。

> 鼠标位置是**主进程直接读系统光标**算的，不是靠网页事件 —— 因为视频跑在独立的
> webview 里，指针移到画面上时宿主页面根本收不到事件。这也是为什么「移开就收回」
> 在视频区上同样可靠。

#### 「移开后」有两种，随便挑

鼠标离开窗口之后，要么留个壳、要么连壳都不要：

| 模式 | 表现 | 怎么回来 |
|---|---|---|
| **变回代码**（默认） | 画面收起，代码面具留在原地 —— 「没来得及隐藏也不明显」 | 鼠标再移进来 |
| **整个窗口藏掉** | 连外壳一起消失，屏幕上干干净净什么都不剩 | 托盘图标点一下，或者 `Alt+V` |

两种都在**三个地方**点得到：右键菜单 →「移开后」、设置面板 →「平时怎么用」、
以及**托盘菜单**（隐藏模式下窗口已经不见了，托盘是唯一还能点到的地方，所以这个
开关必须在那儿也有一份）。

钉住画面、或者菜单 / 设置面板开着的时候不会藏 —— 那两种情况你显然还在用。

## 内置来源

标签栏上每一个「文件名」就是一个来源。菜单里默认同时显示真实名字，好认。

| 标签栏显示 | 实际来源 | 入口 | 比例 |
|---|---|---|---|
| `feed.aggregator.ts` | 抖音 | 桌面版（无可用移动端网页） | 横 |
| `media.player.tsx` | 哔哩哔哩 | 移动版 | 横 |
| `live.room.ts` | 虎牙 | 移动版 | 横 |
| `stream.pipeline.ts` | 快手 | 移动版 | 竖 |
| `realtime.socket.ts` | 斗鱼 | 移动版 | 横 |
| `notes.index.tsx` | 小红书 | 桌面版 | 竖 |
| `timeline.cache.ts` | 微博 | 移动版 | 横 |
| `cdn.proxy.ts` | YouTube | 移动版（需自备网络） | 横 |
| `qa.thread.tsx` | 知乎 | 桌面版 | 横 |

> **抖音第一次打开是扫码登录页**，不是推荐流 —— 扫一次就记住了（登录态按来源独立持久化），
> 之后就正常了。第一次进这个来源时窗口里会自己提示一次。
>
> **登录前先在操作条上点「钉住」**（或双击画面），否则鼠标一离开窗口画面就收回了，
> 没法填手机号和验证码。

### 净化

小窗口里最扎眼的往往不是视频本身，而是那些浮层：下载 App 横幅、登录引导、开屏广告。
操作条上的 **净化** 会往页面里注入一段 CSS 把它们盖掉，顺便把系统粗滚动条换成细的。

写得很保守 —— 只按类名关键字命中（`login-guide` / `open-app` / `interstitial` 之类），
不做布局级猜测，所以不会误伤正文。嫌它盖多了就再点一下关掉。
**每个来源各记各的**。

### 关于亮色页面

抖音这类页面是纯白的，在深色编辑器外壳里会比较跳。
设置里有一项 **画面压暗**（默认 15%）—— 给画面盖一层暗色，从侧后方扫过去就不那么显眼了。
嫌影响观感可以调到 0。

### 加自己的

编辑配置文件（托盘 → 打开配置目录 → `screenfold.json`），在 `custom` 数组里加：

```json
{
  "id": "custom-1",
  "real": "某某",
  "file": "worker.queue.ts",
  "lang": "typescript",
  "url": "https://example.com",
  "ua": "mobile",
  "ratio": "short",
  "dot": "#7fd4c1"
}
```

- `ua`：`mobile` 加载移动端页面（小窗口里更好看），`desktop` 加载桌面版
- `ratio`：`short` 竖屏 9:16 / `wide` 横屏 16:9。窗口会**自动**切到匹配比例，保证画面铺满没有黑边
- 自定义来源没有专属源码，面具会退回默认那份 `feed.aggregator.ts`

## 窗口尺寸

| 预设 | 内容区 | 比例 |
|---|---|---|
| 细条 | 168 × 299 | 9:16 |
| 窄长 | 240 × 427 | 9:16 |
| 迷你 | 264 × 149 | 16:9 |
| 竖屏小 | 296 × 526 | 9:16 |
| 竖屏大 | 340 × 604 | 9:16 |
| 横屏 | 528 × 297 | 16:9 |

菜单里按宽度从小到大排，一眼能看出「还能更小 / 还能更大」。
切来源时会自动切到匹配的比例 —— 内容铺满，不留黑边。

**直接拖窗口边缘**可以任意改大小（走系统原生缩放，右下角有斜纹把手提示）。
自己拖过之后就算「自定义尺寸」，之后切来源只调整高度对齐比例，不会推翻你定的大小。

窗口贴近屏幕边缘时会自动吸附。

**最小尺寸 150 × 132 —— 可以一直拖到「一条细长的侧栏面板」那么大。**
150 宽大约是一行 24 个字符的代码，装成编辑器左边的大纲 / 侧栏面板刚刚好。
再窄就不像话了，所以到此为止。

> ⚠️ 这里踩过坑：早期为了让「误拖」不那么惨，把下限抬到 240、并且把
> **可用门槛**抬到 260 —— 结果是**用户主动想缩小也缩不动**，一拖到 260 以下就被
> 自动弹回上一次的大小，体验上就是「窗口怎么只能这么大」。下限该放宽，
> 误拖要靠下面那道闸去挡，而不是靠抬高下限兜。

误拖的防线（**不是**靠抬高下限）：

1. **窗口刚弹出的 1.5 秒内**，任何缩放请求都被整体作废 —— 这才是「弹出瞬间
   鼠标正按着左键」那个场景的正解。
2. 真拖到了 164 宽以下才判定为误操作，还原上一次的大小，并且这一段拖拽整体作废
   （不会和还原动作来回拉锯）；尺寸不会被写进配置，下次启动照常。

实测日志见 `--sf-debug` 输出。

## 托盘

托盘图标（一个不起眼的深色小方块）右键：

- 显示 / 隐藏面板

- 退出

单击托盘图标 = 显示或隐藏面板。

## 自检模式

跑一遍并自动截图，用来确认伪装效果没被改坏。**双击 `selftest.cmd`** 就行，
也可以带参数（`selftest.cmd --shot=shots`）。

会在 `shots/` 下生成 **14 张图**：五套面具、画面态、操作条、三个菜单、设置、
切到另一个标签后的源码联动，外加**最小尺寸「细条」下的源码面具**和
**「移开后」菜单**各一张。

> 最后两张的尺寸跟前 12 张**不一样**（前 12 张是同一个窗口大小，最后两张是
> 缩到最小之后的），这是故意的 —— 它们就是在验「窗口能不能真的缩到 168 宽」。

日志里每张图前都会打一行 `[state]`，包含当时的 `mask / site / file / dock / menu`
和 `[title]`（窗口标题）。开头那 12 张尺寸应该全部一致，且时间戳连续。

**退出码 0 = 14 张全部写出来了。** 非 0 说明有图没拍成（`[shot fail]` / `[capture timeout]`），
别只看「日志没报错」就以为跑完了。

自检用的是**独立 profile**（`.selftest-userdata/`），好处有三个：

1. **不会跟你正在用的那份抢单实例锁** —— 否则新实例会在 6 秒后静默退出、一张图都不出；
2. **你自己的配置从根上没被碰过**（自检会切来源、换面具、改尺寸，都是配置里的东西）；
3. 每次都从 `selftest-seed.json` 那份固定配置开始，**结果可复现**，不依赖你当时设成什么样。

> 还有一道 180 秒硬兜底：某一步卡住（webview 不回来之类）会自动退出，
> 不会留下一个看不见的后台 Electron。

## 交互设计上踩过的坑

留在这里，免得下次再犯：

- **别把功能绑在快捷键上。** 第一版把换来源 / 换尺寸 / 换面具都做成热键，
  结果没人记得住。摸鱼工具要的是「扫一眼就会用」。
- **别用 `Ctrl+Alt+↑/↓` 注册全局热键** —— 那正好是 VS Code 的「向上/下添加光标」，
  会把用户的编辑器抢走。现在这类操作全部改成窗口内点击。
- **别用 DOM 的 `mouseenter` 判断鼠标进出** —— 视频区在独立 webview 里，
  指针移上去宿主页面收不到事件，会导致「移开自动收回」失效。
  改用主进程轮询系统光标位置。
- **压暗层要放在画面层内部**，否则画面收起时压暗层还盖在面具上，把假代码也压暗了。
- **伪装内容的「自洽」比「精致」重要。** 文件名、代码、窗口标题三者必须同一个文件 ——
  对不上比画得丑更容易被看出来。
- **别用「抬高最小尺寸」去防误拖。** 为了不让一次误拖把窗口缩成一条缝，我曾经把下限
  抬到 240、可用门槛抬到 260 —— 结果是**用户主动想缩小也缩不动**，一拖过 260 就被
  自动弹回去，收到一句「这窗口怎么只能这么大」。正确分工是：**误拖交给时间闸**
  （窗口刚弹出的 1.5 秒内整段拖拽作废），**下限只保证「拖到这儿还是一块能看的屏幕」**。
- **窗口能变窄之后，所有横排的 UI 都要重新检查会不会被裁掉。** 底部操作条原来是
  `flex: none` + 不换行，窄下来之后右边的按钮直接被祖先的 `overflow: hidden`
  切出可视区、**彻底点不到** —— 而截图上看起来只是「按钮变少了」，极易漏过去。
  现在窄窗口下允许换行。**改了尺寸相关的代码，必须在小尺寸下再截一张图逐个数按钮。**
- **`capturePage()` 会挂死。** 把窗口缩到极小、且画面比例跟容器对不上时，截图会
  一直不返回，一张图把整轮自检拖到 watchdog 硬超时。现在有 12 秒超时 + 重试，
  并且「没拍成」会让退出码非 0，不再被无声吞掉。
- **`autoFit` 切来源时别跳到固定那一档。** 原来是「比例不匹配 → 直接切到
  `short` / `wide`」，于是你特意调成的「细条」只要切个来源就会**弹回横屏 528**。
  现在改成「在同比例的预设里挑一个宽度最接近的」。
